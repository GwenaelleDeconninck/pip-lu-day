# PiP-LU Day 2026

Programme booklet for the Junior PI & Postdoc Day at the Department of Biology,
Lund University — Thursday 5 November 2026, Ekologihusets stora entréhall.

**Read it:** https://gwenaelledeconninck.github.io/pip-lu-day/ ·
**Download:** [the PDF](https://gwenaelledeconninck.github.io/pip-lu-day/booklet.pdf)

## How this repository works

Edit `PiP-LU_Day_2026_Booklet.html`, commit, push. A GitHub Action copies it to
`index.html` and republishes the site, usually within a minute.

Only the booklet, its PDF and two image assets are tracked. Everything else in
the working folder — the planning workbook, participant lists, badges — is
excluded by `.gitignore`, because it contains personal data.
